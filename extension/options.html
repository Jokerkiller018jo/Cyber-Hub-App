How global shortcuts work

Chrome can trigger your shortcut even when a different app is focused — as long as Chrome is running in the background. Make sure "Continue running background apps when Google Chrome is closed" is enabled in Chrome Settings → System.

This opens chrome://extensions/shortcuts where you can set any key combination and toggle the Global switch.

How to activate or customize the global shortcut
  1. Copy and open chrome://extensions/shortcuts in a new browser tab
  2. Scroll to CyberHub — Color Picker
  3. Under "Pick color with pen (global shortcut)":
    • Default suggested shortcut is Ctrl+Shift+8 (Mac: Cmd+Shift+8)
    • You can change it to Ctrl+Shift+E, Ctrl+Alt+C, or any combination you like!
  4. Change the dropdown on the right from "In Chrome" to "Global"
  5. Done! You can now press your shortcut from any app or game on your computer!
